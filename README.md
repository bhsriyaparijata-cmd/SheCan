# She Can Foundation Website

This project is a modern and responsive NGO website created for the Frontend Development Internship task at She Can Foundation. 
The website was designed to represent the foundation’s mission of empowering women through education, awareness, skill development, and community support initiatives.

The website includes multiple interactive sections such as a homepage with slideshow animations, mission and vision pages, a donate section, and a contact page.
The design focuses on creating a clean, professional, and user-friendly experience using modern frontend development concepts.

The project was built using HTML, CSS, and JavaScript with responsive layouts, gradient backgrounds, hover effects, animations, and 
interactive UI elements to create a visually appealing and engaging website experience.

This website reflects the values of empowerment, equality, opportunity, and positive social change inspired by the mission of She Can Foundation.
